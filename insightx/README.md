## 🤖 ML Algorithms

| Algorithm | Task | Metric |
|-----------|------|--------|
| **Linear Regression** | Predict energy consumption (kWh) | R², RMSE |
| **Decision Tree** | Classify high vs low usage | Accuracy |
| **KNN** | Predict efficiency category | Accuracy |
| **K-Means** | Cluster consumption groups | 4 clusters |

---

## 📊 Dataset Features (1000+ records)

- Household Size (1–6)
- Appliance Count (2–15)
- Average Temperature (15–42°C)
- Working Hours (4–16h)
- Solar Usage (binary)
- Electricity Tariff (₹3.5–9.5/kWh)
- Day Type (weekday/weekend)
- Previous Consumption (10–80 kWh)
